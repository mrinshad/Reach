How to unblock on Mobile Chrome / Browser
  1. Tap the tune icon (🎛️) or lock / info (🔒 / ℹ️) in your browser address bar (beside the URL).

  3. Find Notifications and change it from Blocked to Allow.
  4. Tap "Check / Request Again" below to activate.
